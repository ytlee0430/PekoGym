# Story 7.2: Daily Mission & Gym Recommendation

Status: ready-for-dev

## Story

As a player,
I want to see a daily recommended gym/muscle group on the home screen,
So that I can follow a structured plan without manual scheduling.

## Acceptance Criteria

1. **Given** the player opens the app
   **When** the home screen loads
   **Then** a "Daily Mission" card displays the recommended muscle group and gym type
2. **And** the recommendation is generated by the Training Scheduler Algorithm (Story 7.1)
3. **And** the recommendation considers training history to avoid overtraining a muscle group
4. **And** the player can accept the recommendation (auto-selects gym) or choose manually
5. **And** completed daily missions grant bonus EXP

## Dev Notes

### CRITICAL — Database Is Drift 2.31.0 (NOT Isar)

Project uses Drift 2.31.0.

### CRITICAL — No riverpod_generator

Manual providers only.

### Dependencies on Previous Stories

- **Story 7.1** — `TrainingScheduler` and `TrainingRecommendation`
- **Story 1.4** — `HomeScreen` for mission card placement
- **Story 2.3** — `GymSelectionScreen` for pre-selection support
- **Story 3.3** — `ExpCalculator` for bonus EXP integration

### Mission Persistence

Daily mission doesn't need its own Drift table for MVP. Store current mission date in memory (provider state). If the app restarts, regenerate from scheduler. The `isCompleted` check can query today's workout sessions.

### Pre-selection Navigation Pattern

Pass mission data via go_router extra:

```dart
context.push('/battle/select', extra: {
  'muscleType': mission.recommendedMuscleTypes.first.name,
  'gymType': mission.recommendedGymType.name,
});
```

In `GymSelectionScreen`, read from `GoRouterState.extra`.
